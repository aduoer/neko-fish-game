# 喵喵捞鱼记 · Neko Fishing

一个轻松可爱的猫咪捞鱼小游戏。套着泳圈的小猫在池塘里移动，碰到小鱼就能捞进篮子，还会开心地冒出一串爱心。60 秒内尽量拿高分吧。

## 玩法

- **移动**：鼠标移动 / 触屏拖动 / WASD / 方向键
- **冲刺**：空格、鼠标左键、双击 / 长按屏幕或右下角冲刺按钮（有 2.4 秒冷却）
- **计分**：
  - 小青鱼 +1
  - 锦鲤 +2
  - 小金鱼 +5（稀有，会冒更多爱心）
  - 鱼王 +20（每局在后期出现一次）
- **连击**：在 2.6 秒内连续捞到鱼，分数倍率最高 ×5
- **连击奖励**：
  - 5 连击：小猫星星眼，开启 4.5 秒磁铁把小鱼吸过来
  - 10 连击：下起爱心雨，并获得 3 秒双倍积分
- **鱼潮**：第 15 秒和第 35 秒各来一次，持续 6 秒，小鱼成群且积分 ×2
- **结算**：根据得分点亮 1–3 颗星，并提示距离下一颗星还差多少分
- **爱心**：小猫每捞到一条鱼，都会冒出粉色爱心

## 本地运行

项目是纯静态页面，无需构建。因为使用了 ES Modules，请通过本地服务器打开：

```bash
cd neko-fish-game
python -m http.server 5173
```

然后访问 <http://localhost:5173>。

## 技术说明

- 原生 HTML / CSS / Canvas 2D，无第三方依赖
- 所有画面（猫、鱼、池塘、粒子）均由代码绘制，无图片资源
- Web Audio 合成音效，可随时静音
- 最高分保存在浏览器 localStorage
- 适配桌面端与移动端，支持触屏和高分屏
