# 喵喵捞鱼记 · Neko Fishing

一个轻松可爱的猫咪捞鱼小游戏。套着泳圈的小猫在池塘里移动，碰到小鱼就能捞进篮子，还会开心地冒出一串爱心。游戏包含经典、每日挑战和耐心无尽三种模式，可以攒金币收集各种猫咪、泳圈和池塘皮肤，也能把成绩导出成卡片分享给朋友。

## 三种模式

- **经典 60 秒**：限时捞鱼，冲高分、点星星。
- **每日挑战**：每天按本地日期生成同一组 3 个目标（得分、金鱼数、最高连击），当天的鱼群序列也由日期种子决定。每个目标奖励 25 金币，三项目标全部完成再额外奖励 50 金币。每日记录和领取状态会在本地 0 点刷新。
- **耐心无尽**：开局耐心 5 秒，每捞到一条鱼就把耐心回满；每累计捞到 10 条鱼，耐心上限 +2 秒（最高 21 秒）。耐心归零时结束，鱼潮和鱼王仍会继续出现。

## 操作

| 操作 | 桌面端 | 触屏 |
| --- | --- | --- |
| 移动小猫 | 鼠标移动 / WASD / 方向键 | 拖动屏幕 |
| 冲刺 | 空格 / 鼠标左键 / 双击屏幕 | 双击 / 长按屏幕 / 右下角冲刺按钮 |
| 猫爪撒网 | 按住 `E` 或鼠标右键蓄力，松开撒网 | 按住左下角撒网按钮蓄力，松开撒网 |

- 冲刺有 2.4 秒冷却。
- 撒网会随蓄力扩大范围，最多蓄力 1.1 秒；撒网后进入 6.5 秒冷却。
- 蓄力时网内的小鱼会减速，方便一网多捞。网外的鱼仍会正常逃跑。
- 猫爪撒网会捕获范围内的所有小鱼，并统一结算分数和金币。

## 计分与连击

- 小青鱼 +1 分、锦鲤 +2 分、小金鱼 +5 分、鱼王 +20 分。
- 在 2.6 秒内连续捞鱼会累积连击，分数倍率最高 ×5。
- 5 连击：小猫星星眼，开启 4.5 秒磁铁把小鱼吸过来。
- 10 连击：下起爱心雨，并获得 3 秒双倍积分。
- 经典和每日模式在第 15 秒、第 35 秒各来一次鱼潮，持续 6 秒，小鱼成群且积分 ×2。
- 结算时根据得分点亮 1–3 颗星，并提示距离下一颗星还差多少分。

## 小鱼图鉴

共 13 种造型随机出现：

- 小青鱼 3 种：蔚蓝、礁湖、银光
- 锦鲤 4 种：红白、丹顶、三色、白写
- 小金鱼 5 种：橙金、红白兰寿、黑龙睛、水泡眼、蝶尾
- 鱼王 1 种

所有鱼都由 Canvas 代码绘制，没有图片资源。小猫捞到鱼时会冒粉色爱心。

## 金币与装扮

每条鱼都会带来金币：小青鱼 / 锦鲤 1 枚、小金鱼 3 枚、鱼王 15 枚。每日挑战目标也会奖励金币。金币、已购买装扮和当前装备都会保存在浏览器 localStorage 中。

- **猫咪**：橘子猫（免费）、奶牛猫 160、三花猫 220、黑猫 260、英短蓝猫 280、狸花猫 300、白猫 340、布偶猫 380、暹罗猫 420、银渐层 460、缅因猫 520、星月猫 680
- **泳圈**：樱花（免费）、蜜桃 90、薄荷 120、柠檬 180、海盐汽水 220、泻湖 260、莓果 320、星夜 380、鱼王 520、彩虹 640
- **池塘**：草甸（免费）、落日 200、抹茶 240、樱花 300、珊瑚 360、夜色 420、紫藤 520、极光 560、糖果泡泡 620

购买后会自动装备，也可以随时在商店里切换已拥有的装扮。每一种猫咪都会改变毛色、花纹、眼睛颜色和耳朵造型，部分长毛猫还有脸颊绒毛、耳簇和小饰品；不同池塘会改变水面渐变、波光、花瓣、睡莲、芦苇和暗角效果。

## 成绩卡片

每局结束后可以打开成绩卡片：

- 生成 1080 × 1350 的 PNG，包含模式、分数、捞鱼数、金鱼数、最高连击、历史最佳、金币、日期和每日目标完成情况。
- 卡片会使用小猫当前的猫咪品种、泳圈和池塘主题。
- 支持直接下载；浏览器支持文件分享时会显示系统分享按钮。

## 保存内容

- 三种模式各自的历史最佳分数
- 金币余额
- 已拥有的猫咪、泳圈、池塘以及当前装备
- 每日挑战的当日最佳、目标领取状态和全清奖励
- 旧版本的经典最高分会自动迁移到新的存档结构

## 本地运行

项目是纯静态页面，无需构建。因为使用了 ES Modules，请通过本地服务器打开：

```bash
cd neko-fish-game
python -m http.server 5173
```

然后访问 <http://localhost:5173>。

## 技术说明

- 原生 HTML / CSS / Canvas 2D，无第三方依赖、无构建步骤
- 所有画面（猫、鱼、池塘、粒子、成绩卡）均由代码绘制，猫咪皮肤由同一套毛色/花纹数据驱动
- Web Audio 合成音效，可随时静音
- 日期种子使用 `mulberry32` 确定性随机数；鱼群生成序列和鱼的行为随机数分离，保证每日挑战可复现
- 使用 Web Locks 串行化跨标签页的金币、购买和每日奖励写入，避免两个标签页互相覆盖存档
- 适配桌面端、移动端横竖屏、刘海安全区和减少动态效果偏好
