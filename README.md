# 喵喵捞鱼记 · Neko Fishing

一个轻松可爱的猫咪捞鱼小游戏。套着泳圈的小猫在池塘里移动，碰到小鱼就能捞进篮子；碰到河豚会扣掉 4 秒。60 秒内尽量拿高分吧。

## 玩法

- **移动**：鼠标移动 / 触屏拖动 / WASD / 方向键
- **冲刺**：空格、鼠标左键或右下角冲刺按钮（有 2.4 秒冷却）
- **计分**：
  - 小青鱼 +1
  - 锦鲤 +2
  - 小金鱼 +5（稀有）
  - 河豚 −4 秒并清空连击
- **连击**：在 2.6 秒内连续捞到鱼，分数倍率最高 ×5

## 本地运行

项目是纯静态页面，无需构建。因为使用了 ES Modules，请通过本地服务器打开：

```bash
cd neko-fish-game
python -m http.server 5173
```

然后访问 <http://localhost:5173>。

## 技术说明

- 原生 HTML / CSS / Canvas 2D，无第三方依赖
- 所有画面（猫、鱼、池塘、粒子）均由代码绘制，无图片资源
- Web Audio 合成音效，可随时静音
- 最高分保存在浏览器 localStorage
- 适配桌面端与移动端，支持触屏和高分屏
